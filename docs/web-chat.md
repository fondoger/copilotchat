# 网页聊天 Providers

Settings → Providers 支持以下网页站点，各站点使用独立的 Provider 图标，名称和会话归属也独立。

| Provider | 新对话入口 |
| --- | --- |
| 豆包 | https://www.doubao.com/chat |
| DeepSeek Web | https://chat.deepseek.com/ |
| Claude Web | https://claude.ai/new |
| Gemini Web | https://gemini.google.com/app |
| ChatGPT Web | https://chatgpt.com/ |

## 使用与登录

在 Settings → Providers 添加站点，保留或修改 Provider name，并在下方完整网页中自行登录。然后在聊天顶栏的 Web Chat 分组选择站点，通过 Copilot Chat 的 New Chat 开始会话。聊天页隐藏网站侧栏和部分顶栏，输入、回复、模型及附件操作仍由网站处理。

登录弹窗使用独立的原生 WebView 窗口，在 Windows/macOS 保留 `window.opener`、`postMessage` 和网站自行关闭弹窗的能力，不再把 popup URL 加载到原聊天页。弹窗共享当前实例的浏览器登录存储，不注入聊天脚本或授予桥接信任；导航仍限制为对应站点与已允许的认证来源，销毁对应 WebView 时一并关闭弹窗。

登录状态由系统 WebView 的持久化浏览器存储管理，设置页与聊天页共享，不会把 Cookie 或网页凭据复制到 `state.json`。Claude Desktop 内置浏览器是另一份浏览器环境，其登录不会自动复制到本应用。同站点的多个 Provider 共用登录，不做独立账号隔离；删除或禁用 Provider 不清除共享登录。`--data-dir` 只切换应用设置与会话目录，不隔离浏览器登录。

## 会话与草稿

只关联从当前本地新对话创建的远端会话，保存网址和自动标题。普通浏览账号历史、在设置页创建或打开会话均不会导入。已绑定的链接不会改绑其他会话；手动命名不被网页标题覆盖，本地删除不删除网站账号中的会话。侧栏先点击一条会话，再按住 Shift 点击另一条，可选中两者之间的可见会话，右键批量删除；删除前需要确认。

尚未开始的会话在原生 API 与网页 Provider 间切换时复用同一本地记录，尽力双向传递纯文字，包括清空。草稿仅存内存，不自动发送。原生附件不上传网站，网页图片不导入；文字未改动的往返保留原生附件，网页修改文字后丢弃先前附件。网页结构或编辑器未就绪时，文字传递可能失败。

重启时清理从未输入内容、未关联远端会话的网页 New Chat 占位记录；已输入过内容、手动命名或收藏的记录保留。是否输入过内容仅保存为标记，不额外持久化草稿文字。

### 创建识别差异

- 豆包观察 `/chat/local_<ID>` → 正式数字 ID 路由，进入临时路由后即视为已开始，不等待标题生成。
- 其余站点观察真实提交意图与紧随其后的正式会话路由；ChatGPT 兼容中间的 `local-chatgpt` 临时路由。
- Gemini 支持带 `/u/<账号索引>/` 的路由，保存网址时保留前缀；这不提供账号管理或自动切换。

无法确认创建归属时保留网页，但不导入或绑定账号历史。

## 导航与资源

同站点复用一个聊天 WebView，优先点击网页原生会话链接或新对话入口，减少整页加载；不调用私有 API。Gemini、ChatGPT 在历史列表未挂载时会尝试通过网站侧栏入口加载，不自动翻页。老会话尚未加载、入口缺失或超时则先导航到 `about:blank`，再加载保存的网址。ChatGPT 历史渲染较慢时仍可能触发回退。

跨站点重建 WebView，防止沿用另一站的脚本及桥接信任。切到原生会话后最多停放五分钟，返回时取消释放；超时销毁 WebView、停止观察并移除监听。关闭应用、删除会话、删除或禁用 Provider 会释放对应页面。

设置环境变量 `COPILOT_CHAT_WEBVIEW_TIMING=1` 可记录页面创建、DOM 就绪、完整加载和同文档切换耗时。

## 快捷键与限制

网页获得焦点后仍可使用应用的 New Chat、搜索、侧栏、模型菜单和会话切换快捷键；普通复制粘贴与输入交给网页。桥接只信任站点精确聊天来源，并校验当前页面和窗口；设置页与认证来源不授予桥接权限。MyGo 的来源信任也包含框架内置窗口操作。

网页聊天不走原生 API，不使用原生模型目录、MCP、消息编辑或 Markdown 导出，也不提供 LLM Gateway 转发。网站登录验证、网络与地区限制、订阅和可用性由站点决定，本集成不绕过检查。网页结构变化可能影响编辑器、导航、隐藏样式和标题识别，必要时使用完整导航或 Retry。
