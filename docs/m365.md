# Microsoft 365 Copilot

在 **Settings → Providers** 点击底部 **+**，选择 **Microsoft 365 Copilot**，填写名称后登录工作账号。

服务地址由应用管理，无需手动配置。当前支持 `df.loki.delve.office.com` 下的模型网关，账号必须具备该服务的访问权限。拥有 Microsoft 365 Copilot 订阅不保证能访问该网关或其中的所有模型。

## 登录

M365 提供两种登录方式：

- **Sign in with Microsoft**：Windows 上直接打开系统 WAM 账号选择器，无需安装 Copilot CLI 或额外认证组件。应用绑定所选工作账号，由 Windows 管理登录和令牌续期。
- **Use Copilot CLI sign-in**：复用本机 Copilot CLI 当前选中的 Microsoft 365 工作账号，需要安装支持 Microsoft Entra 的 Copilot CLI 并先完成登录。应用读取该账号在系统凭据库中的令牌，不复制 CLI 的刷新令牌。

部分租户的 Conditional Access 或 Token Protection 策略会限制设备码和浏览器回调授权。本应用不提供这两种 M365 登录方式，也不会在 WAM 失败后自动切换到它们。GitHub Copilot 的设备码登录不受此实现变化影响。

WAM 入口仅在 Windows 启用。macOS 使用已有 Copilot CLI 登录复用入口，该平台尚未完成实机登录验证。系统凭据库不可用、账号无服务权限或 CLI 复用方式缺少兼容 CLI 时会显示错误；不接受明文凭据保存。

Tenant ID 从所选账号动态读取，应用不限定单一租户。登录和续期时会校验账号身份、令牌签发方和目标服务；应用仅向支持的网关发送令牌。其他租户能否使用模型，取决于租户策略和服务授权。

## 账号与续期

登录后显示工作账号，并从服务获取该账号当前可用的模型。

账号绑定保存于系统凭据库，访问令牌不进入会话 JSON。读取令牌时校验目标资源、租户、对象 ID 和有效期；切换 CLI 账号不会切换现有 Provider 的身份。退出 Provider 会取消该来源的续期并移除应用保存的绑定，不退出 Windows 或全局 CLI 账号。

系统 WAM 登录的 Provider 通过 Windows 为绑定账号续期令牌。复用已有 CLI 登录的 Provider 通过 Copilot CLI 续期，要求 CLI 当前选中的账号与绑定一致；不一致会提示重新选择账号。续期过程不发送聊天内容。

旧版本通过 CLI 完成 Windows 登录的 Provider 仍沿用原登录方式。可退出该 Provider，再点击 **Sign in with Microsoft**，改为无需 CLI 的系统 WAM 登录。

Claude 保留流式消息、图片、thinking effort／budget、工具调用、后续轮次的 thinking 签名回放和缓存输入 token 统计。以服务公布的模型能力为准，只有服务实际返回的 thinking 内容才会显示。

## 平台支持与验证范围

Windows x64 的 WAM 登录和模型访问已完成实机验证。Windows ARM64 和 macOS 已完成构建验证，尚未完成实机登录验证。其他租户的服务授权尚未完成实机验证。

自动化测试覆盖账号隔离、令牌身份校验、续期取消、模型目录、流式响应、工具调用、thinking 和缓存用量统计。
